# publish checklist

## voice

- [ ] quiet, plain, human
- [ ] title is searchable without sounding clickbait
- [ ] no “10 signs,” hustle language, or conversion pressure
- [ ] no fake certainty about what a reader feels
- [ ] no forced happy ending, closure, forgiveness, gratitude, or “growth”

## usefulness

- [ ] direct answer appears early
- [ ] article contains a practical framework, prompt, distinction, or decision aid
- [ ] examples are original/composited
- [ ] no real wall note is reproduced
- [ ] community research is used for patterns, not spectacle
- [ ] article can stand on its own even if the reader never visits the wall

## privacy

- [ ] public-writing advice reminds readers to remove identifying details where relevant
- [ ] no suggestion that “anonymous” automatically means technically private
- [ ] no claims about the wall's data handling unless verified against current production behavior
- [ ] CTA does not imply private content if the wall note is public

## E-E-A-T / claims

- [ ] every number has a current source
- [ ] no invented expert byline or fabricated clinical review
- [ ] mental-health-adjacent claims are descriptive and restrained
- [ ] writing/venting/confession is never sold as treatment
- [ ] grief content does not prescribe a timeline or “moving on”
- [ ] “continuing bonds” is framed as a research concept, not universal advice

## safety

- [ ] distress/grief pages distinguish expression from real-time support
- [ ] 988 / Samaritans / Find A Helpline details verified at publication time
- [ ] no diagnostic quizzes or self-diagnosis language
- [ ] no SEO targeting for suicide-intent or diagnostic head terms
- [ ] if a section discusses immediate danger, support resources appear before the CTA

## CTA

- [ ] one soft CTA, late
- [ ] wall section matches the article's actual emotional job
- [ ] CTA offers no outcome promise
- [ ] where appropriate, reader can simply read the wall rather than leave a note

## dev

- [ ] slug matches routing
- [ ] title/meta fit current template constraints
- [ ] canonical is set
- [ ] Article/BlogPosting schema uses truthful author/date data
- [ ] internal links point to live pages only
- [ ] source links use sensible rel/security attributes
